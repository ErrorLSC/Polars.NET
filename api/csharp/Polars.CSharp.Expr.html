EwmMeanBy(Expr, string)

Compute exponentially-weighted moving average based on a temporal or index column.

public Expr EwmMeanBy(Expr by, string halfLife)

Parameters

by Expr

The column used to determine the distance between observations.

Supported data types: Date, DateTime, UInt64, UInt32, Int64, or Int32.

halfLife string

The unit over which an observation decays to half its value.

Supported string formats:

  • Time unitsns (nanosecond), us (microsecond), ms (millisecond), s (second), m (minute), h (hour), d (day), w (week).
  • Index unitsi (index count). Example: "2i" means decay by half every 2 index steps.
  • CompoundExample: "3d12h4m25s".

Warning: halfLife is treated as a constant duration. Calendar durations such as months (mo) or years (y) are NOT supported because they vary in length. Please express such durations in hours (e.g. use '730h' instead of '1mo').
