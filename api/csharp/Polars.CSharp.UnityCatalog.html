DeltaHistory(string, string, string, int, CloudOptions?)

Retrieves the commit history (audit trail) for a Unity Catalog Delta table as a DataFrame. This includes metadata about who performed what operation, when it occurred, and what parameters were used.

public DataFrame DeltaHistory(string catalogName, string schemaName, string tableName, int limit = 0, CloudOptions? cloudOptions = null)

Parameters

catalogName string

The name of the catalog (e.g., "main").

schemaName string

The name of the schema/database (e.g., "default").

tableName string

The name of the table to audit.

limit int

The maximum number of history commits to retrieve. If 0, retrieves all available history.

cloudOptions CloudOptions

Cloud-specific configurations and credentials resolved via Unity Catalog.

Returns

DataFrame

A DataFrame containing the flattened and formatted history of the table.

Remarks

Data Processing: The raw JSON history from the Delta log is automatically processed:

  • Timestamps are cast to UTC Datetime(TimeUnit, string?).
  • Complex fields like operationMetrics and operationParameters are unnested into flat columns.
  • Columns are reordered to place essential information (version, timestamp, operation) at the beginning.

Note on Versioning: For standard DML operations, the version column might be null in the raw log; rows are sorted by version or timestamp in descending order (latest first) by default.

DeltaRestore(string, string, string, ulong?, DateTime?, bool, bool, CloudOptions?)

Restores a Unity Catalog Delta table to a previous state based on a version number or a timestamp. This operation is atomic and ACID-compliant.

public ulong DeltaRestore(string catalogName, string schemaName, string tableName, ulong? version = null, DateTime? timestamp = null, bool ignoreMissingFiles = false, bool protocolDowngradeAllowed = false, CloudOptions? cloudOptions = null)

Parameters

catalogName string

The name of the catalog (e.g., "main").

schemaName string

The name of the schema/database (e.g., "default").

tableName string

The name of the table to restore.

version ulong?

The specific Delta table version to restore to. Mutually exclusive with timestamp.

timestamp DateTime?

The specific DateTime to restore the table state to. Mutually exclusive with version.

ignoreMissingFiles bool

If true, allows the restore to proceed even if some underlying data files are missing from storage. Use with caution as this may result in a partial restoration.

protocolDowngradeAllowed bool

If true, allows the table to be restored to a version that requires a lower protocol reader/writer version than the current one.

cloudOptions CloudOptions

Cloud-specific configurations and credentials resolved via Unity Catalog.

Returns

ulong

The new version number of the table after the restore operation is committed.

Remarks

How it works: Instead of physically deleting newer data, Restore creates a new commit in the transaction log that reverts the table's metadata and file references to the target state.

Safety: This operation will fail if any required data files have been physically removed (e.g., by a Vacuum operation) unless ignoreMissingFiles is set to true.

Exceptions

ArgumentException

Thrown when both version and timestamp are provided, or when neither is provided.

DeltaVacuum(string, string, string, int?, bool, bool, bool, CloudOptions?)

Physically deletes data files that are no longer referenced by the Delta table and are older than the specified retention threshold. This operation helps reduce storage costs and ensures compliance by removing historical data that is no longer needed.

public long DeltaVacuum(string catalogName, string schemaName, string tableName, int? retentionHours = null, bool enforceRetention = true, bool dryRun = false, bool vacuumModeFull = false, CloudOptions? cloudOptions = null)

Parameters

catalogName string

The name of the catalog (e.g., "main").

schemaName string

The name of the schema/database (e.g., "default").

tableName string

The name of the table to vacuum.

retentionHours int?

The number of hours to retain historical files. Files modified within this window will not be deleted. If null, the table's default retention setting is used.

enforceRetention bool

If true, the operation will fail if retentionHours is less than the table's minimum retention (usually 168h). Set to false only for emergency cleanup, at the risk of corrupting active readers.

dryRun bool

If true, the method returns the number of files that would be deleted without actually removing them.

vacuumModeFull bool

If true, performs a full scan of the object store to find unreferenced files. If false (Lite mode), uses the Delta log to identify files to be removed.

cloudOptions CloudOptions

Cloud-specific configurations and credentials resolved via Unity Catalog.

Returns

long

The total number of physical files deleted from storage (or identified for deletion if dryRun is true).

Remarks

Warning: This is a destructive operation. Once files are vacuumed, you can no longer "Time Travel" to versions that relied on those files.

Retention Period: By default, Delta Lake prevents deleting files younger than 168 hours (7 days) to protect active readers and concurrent transactions.

Exceptions

ArgumentException

Thrown when retentionHours is a negative value.

OptimizeCatalogTable(string, string, string, long, Dictionary<string, string>?, IEnumerable<string>?, CloudOptions?)

Optimizes the storage layout of a Unity Catalog Delta table by compacting small files and optionally applying Z-Order clustering. This operation significantly improves read performance by reducing file-open overhead and enabling efficient data skipping.

public long OptimizeCatalogTable(string catalogName, string schemaName, string tableName, long targetSizeMb = 128, Dictionary<string, string>? partitionFilters = null, IEnumerable<string>? zOrderColumns = null, CloudOptions? cloudOptions = null)

Parameters

catalogName string

The name of the catalog (e.g., "main").

schemaName string

The name of the schema/database (e.g., "default").

tableName string

The name of the table to optimize.

targetSizeMb long

The target size for the compacted Parquet files in Megabytes. Default is 128 MB.

partitionFilters Dictionary<string, string>

Optional filters to limit the optimization to specific partitions (e.g., {"date": "2024-01-01"}). If null, the entire table is processed.

zOrderColumns IEnumerable<string>

An optional collection of column names to use for Z-Order clustering.

cloudOptions CloudOptions

Cloud-specific configurations, including storage credentials and retry logic for concurrent commits.

Returns

long

The total number of files that were successfully compacted/optimized during the operation.

Remarks

Compaction: Groups small Parquet files into larger ones based on the targetSizeMb.

Z-Ordering: If zOrderColumns are provided, the data is rearranged into multidimensional clusters. This co-locates related information, allowing the engine to skip entire files during queries that filter on these columns.

Deletion Vector (DV) Materialization: If the table uses DVs, this operation physically removes any soft-deleted rows tracked by the vectors. The newly written files will be "clean," and their associated deletion vectors will be removed.

Exceptions

ArgumentException

Thrown when targetSizeMb is less than or equal to 0.
