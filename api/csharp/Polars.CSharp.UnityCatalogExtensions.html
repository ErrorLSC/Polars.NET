MergeCatalogRecords(LazyFrame, UnityCatalog, string, string, string, string[], bool, CloudOptions?)

public static DeltaMergeBuilder MergeCatalogRecords(this LazyFrame sourceData, UnityCatalog catalog, string catalogName, string schemaName, string tableName, string[] mergeKeys, bool canEvolve = false, CloudOptions? cloudOptions = null)

Parameters

sourceData LazyFrame

A LazyFrame containing the data to be merged into the target table.

catalog UnityCatalog
catalogName string

The Unity Catalog name (e.g., "main").

schemaName string

The schema/database name within the catalog.

tableName string

The target Delta table name registered in the catalog.

mergeKeys string[]

An array of column names used as join keys to match source rows with target rows.

canEvolve bool

If true, enables Schema Evolution, allowing the target table's schema to be updated if the source contains new columns.

cloudOptions CloudOptions

Cloud-specific configurations (S3/Azure/GCS) including dynamic credentials resolved via Unity Catalog.

Returns

DeltaMergeBuilder

A DeltaMergeBuilder used to configure "WhenMatched" and "WhenNotMatched" clauses.

Remarks

This is a builder pattern. No data is modified until .Execute() is called on the resulting DeltaMergeBuilder. The operation performs a join between the source and target based on the mergeKeys.

Parameters

catalogName string

The name of the catalog (e.g., "main").

The name of the schema/database (e.g., "default").

The name of the table to sink.

partitionBy IntoSelector?

The selector(s) to partition the data by. Directories will be created in the format "col=value".

includeKeys bool

Whether to include the partition keys in the Parquet files themselves. Default is true (recommended for Delta Lake compatibility).

keysPreGrouped bool

maxRowsPerFile int

Maximum number of rows per file. 0 means no limit.

approxBytesPerFile long

Approximate size in bytes per file. 0 means no limit.

compression ParquetCompression

Compression codec to use (Snappy, Zstd, etc.).

compressionLevel int

Compression level (depends on the codec).

statistics bool

Write statistics to the Parquet file. Delta Lake uses these stats for data skipping, so 'true' is highly recommended.

rowGroupSize uint

Target row group size (in rows).

dataPageSize uint

Target data page size (in bytes).

compatLevel int

IPC format compatibility.

maintainOrder bool

Maintain the order of the data.

syncOnClose SyncOnClose

Whether to sync the file to disk on close.

mkdir bool

Create parent directories if they don't exist.

cloudOptions CloudOptions

Options for cloud storage authentication and configuration.
