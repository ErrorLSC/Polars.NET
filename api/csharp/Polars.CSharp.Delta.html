Delete(string, Expr, CloudOptions?)

Deletes rows from a Delta Lake table that match a given predicate.

By default, this operation performs a Copy-on-Write (CoW), meaning any underlying data files containing matching rows are entirely rewritten.

Note: If Deletion Vectors are enabled on the table, this operation automatically shifts to a Merge-on-Read (MoR) approach. Instead of expensive file rewrites, deleted rows are swiftly marked in a separate deletion vector file, which drastically improves deletion performance. 

public static void Delete(string path, Expr predicate, CloudOptions? cloudOptions = null)

Optimize(string, long, Dictionary<string, string>?, IEnumerable<string>?, CloudOptions?)

Optimizes the layout of the Delta table by compacting small files (bin-packing) and optionally applying Z-Order clustering.

This operation significantly improves read performance by reducing the number of files and co-locating related data.

Note: If Deletion Vectors (DV) are enabled on the table, any soft-deleted rows tracked by the vectors will be physically removed (materialized) from the newly compacted Parquet files, effectively clearing the deletion vectors for the optimized partitions. 

public static long Optimize(string path, long targetSizeMb = 128, Dictionary<string, string>? partitionFilters = null, IEnumerable<string>? zOrderColumns = null, CloudOptions? cloudOptions = null)

Parameters

path string

The root URI of the Delta table.

targetSizeMb long

The target file size in Megabytes for the compacted files (default: 128 MB).

partitionFilters Dictionary<string, string>

Optional dictionary of partition key-value pairs to restrict optimization to specific partitions.

Example: new Dictionary<string, string> { { "date", "2024-01-01" } }

zOrderColumns IEnumerable<string>

Optional list of column names to apply Z-Order clustering.

Z-Ordering co-locates data based on these columns, significantly speeding up queries that filter on them.

cloudOptions CloudOptions

Cloud storage credentials and configuration.

Returns

long

The number of new data files created during the optimization process.

Exceptions

ArgumentException

Thrown if the path is empty or target size is invalid.

Vacuum(string, int?, bool, bool, bool, CloudOptions?)

Recursively delete files and directories in the table that are no longer needed by the table for maintaining the transaction history.

public static long Vacuum(string path, int? retentionHours = null, bool enforceRetention = true, bool dryRun = false, bool vacuumModeFull = false, CloudOptions? cloudOptions = null)

Parameters

path string

The root URI of the Delta table (e.g., "s3://bucket/table").

retentionHours int?

The retention threshold in hours. Files removed before this threshold will be deleted. Set to -1 to use the default retention period configured in the table (usually 168 hours / 7 days).

enforceRetention bool

If true, prevents the vacuum command from deleting files that have not yet reached the retention threshold. Setting this to false allows forcing deletion of recent files (use with caution).

dryRun bool

If true, simply returns the number of files that would be deleted, without actually deleting them.

vacuumModeFull bool

Specifies the vacuum mode:

false (Lite): Only removes files that are explicitly referenced as removed in the transaction log. Faster.

true (Full): Scans the entire storage directory to find and remove any files not referenced in the transaction log (including orphan files from failed writes). Slower but more thorough.

cloudOptions CloudOptions

Cloud storage credentials and configuration (e.g. AWS Keys, Azure Secrets).

Returns

long

The number of files deleted (or selected for deletion in dry-run mode).
