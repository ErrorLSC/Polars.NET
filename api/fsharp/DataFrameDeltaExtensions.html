DataFrameDeltaExtensions

Namespace: Polars.FSharp

MergeDeltaOrdered

Starts a fluent builder to merge a DataFrame into a Delta Lake table with strict, order-preserving SQL MERGE semantics.

Unlike traditional merge methods, this builder guarantees that chained actions (Update, Delete, Insert) are evaluated exactly in the order they are defined. If no actions are specified before execution, it intelligently defaults to a standard Upsert (WhenMatchedUpdate + WhenNotMatchedInsert).

// Signature:
this: DataFrame -> path: string -> mergeKeys: Seq<string> -> canEvolve: Option<bool> -> cloudOptions: Option<CloudOptions> -> DeltaMergeBuilder

Parameters

Name Type Description
this DataFrame -
path string The URI to the target Delta Lake table (local or cloud).
mergeKeys Seq<string> The column names to join on (must exist in both the Source DataFrame and Target Delta table).
canEvolve Option<bool> If set to true, allows schema evolution (e.g., adding new columns from the Source to the Target). Default is false.
cloudOptions Option<CloudOptions> Cloud storage credentials and configuration (e.g., AWS S3, Azure Blob).

Returns

A DeltaMergeBuilder instance used to chain match conditions, culminating in a call to .Execute().
