Merge

Namespace: Polars.FSharp

execute

Executes the merge plan lazily, returning a LazyFrame that can be further transformed or collected later. Validates the plan before building the AST.

// Signature:
plan: MergePlan -> LazyFrame

Parameters

Name Type Description
plan MergePlan The fully constructed MergePlan.

Returns

A LazyFrame representing the merged result (not yet materialized).

executeEager

Executes the merge plan eagerly, materializing the result into a DataFrame. This is the terminal operation for a merge pipeline when a concrete result is needed.

// Signature:
engine: Engine -> plan: MergePlan -> DataFrame

Parameters

Name Type Description
engine Engine The Polars execution engine to use (e.g., Engine.Auto).
plan MergePlan The fully constructed MergePlan.

Returns

A materialized DataFrame containing the merged data.

explain

Returns the optimized execution plan for the merge operation as a string, using Polars' EXPLAIN mechanism. This is useful for performance tuning.

// Signature:
plan: MergePlan -> string

Parameters

Name Type Description
plan MergePlan The constructed MergePlan.

Returns

A string representing the query plan (e.g., optimized logical/physical plan).

includeNulls

Controls whether null values from the source should overwrite existing target values during a default column update (when no explicit setters are provided).

// Signature:
flag: bool -> plan: MergePlan -> MergePlan

Parameters

Name Type Description
flag bool If true, nulls from the source will overwrite target values.
plan MergePlan The current MergePlan being constructed.

Returns

A new MergePlan with the updated IncludeNulls setting.

initiate

Initializes a Merge plan from a target and source LazyFrame, using the provided join key columns. This is the module-level equivalent of calling myTarget.Merge(source, on).

// Signature:
source: LazyFrame -> on: Seq<string> -> target: LazyFrame -> MergePlan

Parameters

Name Type Description
source LazyFrame The source LazyFrame containing the updates.
on Seq<string> The resolved join key column names.
target LazyFrame The target LazyFrame to be updated.

Returns

A new MergePlan ready for further configuration via Merge.whenXxx functions.

whenMatchedDelete

Adds a "WHEN MATCHED DELETE" action to the merge plan. If the condition is not provided, all matched rows are deleted.

// Signature:
condition: Option<FSharpFunc<MergeContext, Expr>> -> plan: MergePlan -> MergePlan

Parameters

Name Type Description
condition Option<FSharpFunc<MergeContext, Expr>> Optional condition expression builder using the MergeContext.
plan MergePlan The current MergePlan being constructed.

Returns

A new MergePlan with the DELETE action appended.

whenMatchedUpdate

Adds a "WHEN MATCHED UPDATE" action to the merge plan. If the condition is not provided, all matched rows are updated. If setters are not provided, all source columns with matching names will overwrite target columns (respecting includeNulls). If explicit setters or a SetterSpec are given, only those columns are updated.

// Signature:
condition: Option<FSharpFunc<MergeContext, Expr>> -> setters: Option<SetterSpec> -> plan: MergePlan -> MergePlan

Parameters

Name Type Description
condition Option<FSharpFunc<MergeContext, Expr>> Optional condition expression builder using the MergeContext (source/target column accessors).
setters Option<SetterSpec> Optional SetterSpec defining which columns to update and how.
plan MergePlan The current MergePlan being constructed.

Returns

A new MergePlan with the UPDATE action appended.

whenMatchedUpdateAll

Convenience shorthand for whenMatchedUpdate None None – updates all matched rows using all source columns (with includeNulls controlling null overwrites).

// Signature:
plan: MergePlan -> MergePlan

Parameters

Name Type Description
plan MergePlan The current MergePlan being constructed.

Returns

A new MergePlan with an unconditional, full-row UPDATE action appended.

whenMatchedUpdateSet

Convenience shorthand for whenMatchedUpdate None (Some setters) – updates all matched rows but only the columns specified by the setters.

// Signature:
setters: SetterSpec -> plan: MergePlan -> MergePlan

Parameters

Name Type Description
setters SetterSpec The SetterSpec (built via Set.build) defining which columns to update.
plan MergePlan The current MergePlan being constructed.

Returns

A new MergePlan with an unconditional, setter-defined UPDATE action appended.

whenNotMatchedBySourceDelete

Adds a "WHEN NOT MATCHED BY SOURCE DELETE" action to the merge plan. This deletes rows from the target that have no matching row in the source, optionally filtered by a condition.

// Signature:
condition: Option<FSharpFunc<MergeContext, Expr>> -> plan: MergePlan -> MergePlan

Parameters

Name Type Description
condition Option<FSharpFunc<MergeContext, Expr>> Optional condition expression builder using the MergeContext.
plan MergePlan The current MergePlan being constructed.

Returns

A new MergePlan with the DELETE (by source) action appended.

whenNotMatchedInsert

Adds a "WHEN NOT MATCHED INSERT" action to the merge plan. If the condition is not provided, all unmatched source rows are inserted. If setters are not provided, all source columns are inserted as-is. If setters are given, only those columns are populated (with the rest set to null/default).

// Signature:
condition: Option<FSharpFunc<MergeContext, Expr>> -> setters: Option<SetterSpec> -> plan: MergePlan -> MergePlan

Parameters

Name Type Description
condition Option<FSharpFunc<MergeContext, Expr>> Optional condition expression builder using the MergeContext.
setters Option<SetterSpec> Optional SetterSpec defining which columns to populate in the new row.
plan MergePlan The current MergePlan being constructed.

Returns

A new MergePlan with the INSERT action appended.

whenNotMatchedInsertAll

Convenience shorthand for whenNotMatchedInsert None None – inserts all unmatched source rows with all source columns.

// Signature:
plan: MergePlan -> MergePlan

Parameters

Name Type Description
plan MergePlan The current MergePlan being constructed.

Returns

A new MergePlan with an unconditional, full-row INSERT action appended.
