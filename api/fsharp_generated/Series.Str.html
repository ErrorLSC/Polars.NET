FindMany ​

Return the bytes offset of all non-overlapping substrings matching a pattern. If the pattern is not found, an empty list is returned.

fsharp
member FindMany(
    patterns: Expr,
    ?asciiCaseInsensitive: bool,
    ?overlapping: bool,
    ?leftmost: bool
) : Series

Parameters

NameTypeDescription
patternsExprAn expression yielding string patterns to search. This method supports matching on string literals only, and does not support regular expression matching.
asciiCaseInsensitivebool (optional)Enable ASCII-aware case-insensitive matching. When this option is enabled, searching will be performed without respect to case for ASCII letters (a-z and A-Z) only.
overlappingbool (optional)Whether matches may overlap. This is only supported when the search pattern contains a wildcard.
leftmostbool (optional)Guarantees in case there are overlapping matches that the leftmost match is used. In case there are multiple candidates for the leftmost match the pattern which comes first in patterns is used. May not be used together with overlapping = True.
