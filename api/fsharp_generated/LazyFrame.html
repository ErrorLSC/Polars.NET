LazyFrame ​

Namespace: Polars.FSharp

A LazyFrame represents a logical plan of operations that will be optimized and executed only when collected.

Operations on LazyFrame are not executed immediately. Instead, they build a query plan. Use Collect() to execute the plan and get a DataFrame.
