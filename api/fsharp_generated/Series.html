Extracts the raw unmanaged pointer and shape metadata of the underlying physical Arrow memory. Designed for zero-copy integrations with native C++ Machine Learning backends like ONNX Runtime or TorchSharp.

NameTypeDescription
shapeReadOnlySpan<IntPtr>-

Returns: A tuple containing the raw IntPtr to the first element, and a long[] representing the tensor shape.

NOTE

DANGER (LIFECYCLE WARNING): This is a zero-copy operation. The returned IntPtr points directly to native memory managed by the Rust Polars engine. It is ONLY valid as long as this Series instance remains alive. You MUST ensure the Series is not garbage collected or explicitly disposed while the native pointer is still in use by an external FFI library, otherwise it will result in a fatal segmentation fault.

AsTensor ​

Deep copies the underlying Arrow memory into a managed .NET Tensor{T} on the garbage-collected heap. Automatically infers the rank and dimensions: 1D data is promoted to a [N, 1] column vector, while 2D nested data becomes an [N, M] matrix.

Deep copies the underlying Arrow memory into a managed .NET Tensor{T} with an explicit N-dimensional shape.

fsharp
member AsTensor : unit -> Tensor<'T>
member AsTensor(shape: ReadOnlySpan<IntPtr>) : Tensor<'T>

Parameters

NameTypeDescription
shapeReadOnlySpan<IntPtr>The target dimensions. The total number of elements must match the underlying Arrow memory length.

Returns: A new managed Tensor{T} containing the copied data. / A new managed Tensor{T} reshaped to the specified dimensions.

NOTE

Unlike AsTensorSpan{T}, this method allocates memory and performs a safe physical copy. The returned Tensor is completely independent of the Polars engine, making it safe to pass across threads or await inside asynchronous (async/Task) workflows. This method performs a safe physical copy to the managed heap. It is highly useful when reshaping flat or nested Arrow arrays into higher-dimensional structures (e.g., 3D/4D image batches like [Batch, Channel, Height, Width]) required by Machine Learning models.
