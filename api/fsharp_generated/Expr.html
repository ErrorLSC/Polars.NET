Expr ​

Namespace: Polars.FSharp

Represents a Polars Expression (lazy evaluation). Expressions are the building blocks of Polars queries, representing columns, literals, or transformations.

Parameters

NameTypeDescription
alphafloatSpecify smoothing factor alpha directly.
Constraint: 0 < alpha <= 1

biasbool (optional)If true, use a biased estimator (Standard deviation uses N in denominator). If false, use an unbiased estimator (Standard deviation uses N-1).
Note: This is primarily relevant for Variance/StdDev. For Mean, it typically defaults to true.

EwmMeanBy ​

Compute exponentially-weighted moving average based on a temporal or index column.

fsharp
member EwmMeanBy(by: Expr, halfLife: string) : Expr

Parameters

NameTypeDescription
byExprThe column used to determine the distance between observations.
Supported data types: Date, DateTime, UInt64, UInt32, Int64, or Int32.
halfLifestringThe unit over which an observation decays to half its value.
Supported string formats:

- Time unitsns (nanosecond), us (microsecond), ms (millisecond), s (second), m (minute), h (hour), d (day), w (week). - Index unitsi (index count). Example: "2i" means decay by half every 2 index steps. - CompoundExample: "3d12h4m25s".

Warning:halfLife is treated as a constant duration. Calendar durations such as months (mo) or years (y) are NOT supported because they vary in length. Please express such durations in hours (e.g. use '730h' instead of '1mo').

Returns: A new expression representing the time/index-based EWM mean.
