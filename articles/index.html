Documentation & Guides ​

Welcome to the Polars.NET documentation and user guides. Here you will find quickstarts, idiom patterns, LINQ guides, and ecosystem interop references.

Getting Started ​

  • Introduction - Core architecture, Lazy vs Eager evaluation, and streaming engine.
  • Quick Start - Installing packages and writing your first DataFrame queries.

Core Concepts ​

  • Expressions & Computations - Vectorized SIMD model, arithmetic & logic, column selectors, when/then branching, window functions (Over), and AST introspection.
  • LazyFrame & Query Optimization - Deferred execution graph, Predicate & Projection pushdown, streaming execution, and async streaming batches.
  • Time Series & Advanced Analytics - Temporal data types, Expr.Dt calendar operations, timezone conversions, dynamic rolling windows, and null interpolation.

Storage & Lakehouse ​

  • Delta Lake & ACID Storage - ACID transactions, Time Travel, metadata audit logs, Z-Order file compaction, CDC streaming, and ordered SQL MERGE.

Language Guides & Idioms ​

  • C# Idioms & Best Practices - Fluent method chaining, collection expressions, schema mapping, and memory safety.
  • F# Idioms & Best Practices - Pipeline combinators, anonymous record queries, and typed projections.
  • LINQ & Query Expressions - 3-tier fallback strategy, LINQ to Polars, and F# query { ... } computation expressions.

Interoperability & Platform ​

  • Ecosystem & Native Interop - Native runtime package distribution, Arrow C Data Interface, ADBC, ADO.NET, ML.NET DataView, and Tensors.
