# API Reference

Polars.NET provides comprehensive API references for both C# and F#.

## C# API Reference
- [DataFrame](/api/csharp_generated/DataFrame) - Eager DataFrame API
- [LazyFrame](/api/csharp_generated/LazyFrame) - Lazy evaluation and query planner API
- [Expr](/api/csharp_generated/Expr) - Column expressions, arithmetic, strings, dates, and window functions
- [Series](/api/csharp_generated/Series) - 1D Arrow-backed columnar array
- [Polars & Selectors](/api/csharp_generated/Polars) - DSL entry points and column selectors
- [PolarsSchema](/api/csharp_generated/PolarsSchema) - Schema inspection and column types
- [LinqExtensions](/api/csharp_generated/LinqExtensions) - LINQ query extensions

## F# API Reference
- [pl](/api/fsharp_generated/pl) - Idiomatic F# DSL module
- [DataFrame](/api/fsharp_generated/DataFrame) - Functional DataFrame combinators
- [LazyFrame](/api/fsharp_generated/LazyFrame) - Functional LazyFrame combinators
- [Expr](/api/fsharp_generated/Expr) - F# expression builders
- [Series](/api/fsharp_generated/Series) - F# Series functions
- [Query](/api/fsharp_generated/Query) - F# Query computation expression extensions
- [Merge](/api/fsharp_generated/Merge) - Functional Merge operators
